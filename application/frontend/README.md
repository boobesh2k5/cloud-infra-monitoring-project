# ⚡ NOVA LUXE - Frontend Storefront (INR ₹)

All client-side code, styling, and interactive features.

## Structure
- `index.html` — Main Single Page Application (modals, hero, search, cart, checkout)
- `css/style.css` — Custom glassmorphism, animations, dark/light themes
- `js/products.js` — 24 curated products in INR with optional backend API sync
- `js/cart.js` — Cart state, localStorage persistence, coupon engine
- `js/checkout.js` — Error-friendly validation & order placement
- `js/app.js` — UI controller (filters, search, modals, wishlist, tracking)
- `start.bat` — 1-click launcher for frontend on http://localhost:4173

## How to Run
Double click `start.bat` or open `index.html` directly in any browser.
No packages to install!
